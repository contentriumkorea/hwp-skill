# 지원 환경과 제한 사항

## Phase 1 기본 계약

- 기본 실행 모드는 `silent`다.
- `silent`는 현재 사용자 세션의 `Hwp.exe`를 실행하지 않고 사용자 포커스를 바꾸지
  않는다.
- `silent`는 `.hwpx`를 직접 엔진으로 읽기 전용 검사할 수 있다.
- HWP/HWT `hwp-portable` 엔진은 아직 준비되지 않아 `silent` 읽기·작성·편집은
  `BLOCKED`다.
- `interactive`는 사용자가 현재 요청에서 한컴 창 실행을 명시한 경우에만 허용한다.
- `isolated-native`는 별도 작업자가 구성되지 않았으면 `BLOCKED`다.
- 준비되지 않은 엔진을 만났다고 GUI로 자동 전환하지 않는다.
- 결과 파일 자동 열기와 포커스 탈취는 금지한다.

## 사용자 대화 경계

- `BLOCKED`, `FAILED`, 엔진 이름, 원시 명령, 내부 계획과 작업 폴더는 실행 기록이며
  일반 사용자 대화에 단계별로 노출하지 않는다.
- `승인`이나 `진행`만으로 `interactive`를 선택하지 않는다. 한컴 창을 열거나 화면에
  보이게 작업하라는 현재 요청이 있을 때만 interactive 예외를 검토한다.
- 보안 모듈이 없거나 조건부 기능을 사용할 수 없을 때 작업 중간에 설치·등록 선택지를
  묻지 않는다. 요청 형식을 바꾸지 않고, 원본을 보존한 뒤 한 번의 간결한 제한 보고로
  종료한다.

## 형식별 지원

| 형식 | 읽기·검사 | 편집 | 새 결과 | 비고 |
|---|---:|---:|---:|---|
| HWP | 조건부 | 조건부 | 조건부 | `silent`는 `BLOCKED`, 다른 모드는 별도 준비 필요 |
| HWT | 조건부 | 조건부 | HWP | `silent`는 `BLOCKED`, 결과는 항상 별도 HWP |
| HWPX | 지원 | 미지원 | 미지원 | `silent` 직접 엔진 읽기 전용 검사 제공 |

HWPX 검사는 ZIP 경로 탈출, 비정상 압축 크기, 외부 XML 개체를 차단한다. HWP/HWT는
Phase 1 기본 경로에서 `hwp-portable`이 준비되지 않아 `silent` 읽기·작성·편집을
완료로 주장하지 않는다.

## 보안 모듈에 따른 조건부 기능

다음 기능은 실행 모드와 한컴 보안 모듈이 모두 준비되어야 하며, 하나라도 없으면
`BLOCKED`다.

- 이미지 삽입과 교체
- PDF 내보내기
- 한컴 네이티브 쪽 이미지 생성

이 상태는 엔진의 내부 결과다. 일반 요청에서 이를 해결하려고 현재 사용자 세션의
한컴을 열거나 GUI 자동화로 우회하지 않는다.

현재 저장소는 Phase 1 공개 문서화 단계이므로, HWP/HWT 편집 범위를 완료 기능처럼
약속하지 않는다. 이후 엔진이 준비되더라도 별도 구현 Task와 검증이 끝나기 전까지 이
문서를 앞서서 해석하면 안 된다.

## 시각 검증 한계

문서의 본문과 구조 재검사는 준비된 실행 모드에서만 가능하다. PDF와 페이지 이미지
생성은 보안 모듈과 로컬 렌더러가 있을 때만 가능하다. 이 조건이 없으면 결과 상태는
`PASS_WITH_WARNINGS` 또는 `BLOCKED`이며 다음을 주장하지 않는다.

- 원본과 픽셀 단위로 동일함
- 줄바꿈과 페이지 나눔이 완전히 유지됨
- 글꼴 대체나 개체 잘림이 없음
- 모든 인쇄 설정이 동일함

중요한 공공문서 결과는 준비된 엔진으로 결과가 생성된 이후에만 한글 프로그램에서
최종 페이지를 사람이 확인해야 한다.

## 제외 범위

- 사용자가 한글 프로그램에서 이미 열어 둔 문서의 직접 제어
- 사용자가 요청하지 않은 `interactive` 실행
- 준비되지 않은 `silent` HWP/HWT 경로의 GUI 자동 대체
- 결과 파일 자동 열기와 포커스 변경
- 다른 사용자의 열려 있는 문서 저장·닫기
- 원본 자동 덮어쓰기
- 암호·DRM·배포용 문서·전자서명 우회
- 매크로 실행
- 외부 AI API나 문서 변환 서버 업로드
- Windows가 아닌 운영체제에서 네이티브 편집
