# 지원 환경과 제한 사항

## Phase 1 기본 계약

- 기본 실행 모드는 `silent`다.
- `silent`는 현재 사용자 세션의 `Hwp.exe`를 실행하지 않고 사용자 포커스를 바꾸지
  않는다.
- `silent`는 `.hwpx`를 ZIP/XML로 직접 읽고 새 HWPX를 직접 작성할 수 있다.
- `silent`는 Windows 기본 OLE 복합파일 API로 보호되지 않은 HWP 5.x `.hwp`와 `.hwt`의
  본문 및 표·그림·수식 개체 목록을 읽을 수 있다. 한컴오피스와 보안 모듈은 필요 없다.
- 새 결과가 HWP이면 HWPX 작업본을 먼저 완성·검증한 뒤 마지막에만 숨김 변환한다.
- HWP/HWT 원본 양식의 직접 편집·변환은 HWPX 양식으로 준비되지 않은 경우 자동 실행하지
  않는다.
- `interactive`는 사용자가 현재 요청에서 한컴 창 실행을 명시한 경우에만 허용한다.
- `isolated-native`는 별도 작업자가 구성되지 않았으면 `BLOCKED`다.
- 준비되지 않은 엔진을 만났다고 GUI로 자동 전환하지 않는다.
- 결과 파일 자동 열기와 포커스 탈취는 금지한다.

## 사용자 대화 경계

- `BLOCKED`, `FAILED`, 엔진 이름, 원시 명령, 내부 계획과 작업 폴더는 실행 기록이며
  일반 사용자 대화에 단계별로 노출하지 않는다.
- `승인`이나 `진행`만으로 `interactive`를 선택하지 않는다. 한컴 창을 열거나 화면에
  보이게 작업하라는 현재 요청이 있을 때만 interactive 예외를 검토한다.
- 보안 모듈이 없거나 조건부 기능을 사용할 수 없을 때 작업 중간에 설치·등록 선택지를
  묻지 않는다. 요청 형식을 바꾸지 않고, 원본을 보존한 뒤 한 번의 간결한 제한 보고로
  종료한다.

## 형식별 지원

| 형식 | 읽기·검사 | 편집 | 새 결과 | 비고 |
|---|---:|---:|---:|---|
| HWP | 지원 | 조건부 | 조건부 | HWP 5.x 읽기 지원, 새 결과는 HWPX 작성 후 마지막 숨김 변환 |
| HWT | 지원 | 조건부 | HWP | HWP 5.x 읽기 지원, 원본 편집은 HWPX 양식이 없으면 차단 |
| HWPX | 지원 | 지원 | 지원 | `silent` ZIP/XML 직접 작업, HWP 요청 시 마지막 변환 |

HWPX 작업은 ZIP 경로 탈출, 비정상 압축 크기, 외부 XML 개체를 차단한다. HWPX가
정식 작업본이며, HWP 바이너리는 기존 문서의 읽기 입력 또는 최종 납품 형식으로만
다룬다. 변환 실패 시 HWPX 작업본을 보존하고 확장자만 바꾼 가짜 HWP를 만들지 않는다.

휴대형 HWP 읽기는 HWP 5.x의 논리 구조를 대상으로 한다. 암호, 배포용 문서, DRM 등
보호 플래그는 우회하지 않으며 HWP 3.x는 현재 지원하지 않는다. 읽기 결과는 본문과
개체 목록의 구조 검사이고, 한컴 레이아웃 엔진의 페이지 배치 결과는 아니다. 머리말,
각주, 숨김 설명처럼 논리 구조에 포함된 텍스트가 추출될 수 있으므로 화면에 보이는
문자열과 완전히 같다고 간주하지 않는다.

## 보안 모듈에 따른 조건부 기능

다음 기능은 한컴 네이티브 엔진과 보안 모듈이 모두 필요한 조건부 기능이다. 기존
HWP/HWT의 휴대형 읽기는 이 목록에 포함되지 않는다.

- HWP/HWT 원본의 네이티브 이미지 삽입과 교체
- PDF 내보내기
- 한컴 네이티브 쪽 이미지 생성

이 상태는 엔진의 내부 결과다. 일반 요청에서 이를 해결하려고 현재 사용자 세션의
한컴을 열거나 GUI 자동화로 우회하지 않는다.

새 HWPX 문서의 이미지 삽입은 HWPX BinData 직접 패키징으로 수행하므로 한컴 보안
모듈을 사용하지 않는다. 기존 HWP/HWT 양식의 네이티브 개체 교체와 PDF·쪽 이미지
내보내기는 별도 엔진 및 보안 모듈 조건을 따른다.

## 시각 검증 한계

HWP 5.x와 HWPX의 본문·개체 구조 검사는 `silent`에서 가능하다. PDF와 페이지 이미지
생성은 보안 모듈과 로컬 렌더러가 있을 때만 가능하다. 이 조건이 없으면 결과 상태는
`PASS_WITH_WARNINGS` 또는 `BLOCKED`이며 다음을 주장하지 않는다.

- 원본과 픽셀 단위로 동일함
- 줄바꿈과 페이지 나눔이 완전히 유지됨
- 글꼴 대체나 개체 잘림이 없음
- 모든 인쇄 설정이 동일함

중요한 공공문서 결과는 준비된 엔진으로 결과가 생성된 이후에만 한글 프로그램에서
최종 페이지를 사람이 확인해야 한다.

## 제외 범위

- 사용자가 한글 프로그램에서 이미 열어 둔 문서의 직접 제어
- 사용자가 요청하지 않은 `interactive` 실행
- 지원되지 않거나 보호된 `silent` HWP/HWT의 GUI 자동 대체
- 결과 파일 자동 열기와 포커스 변경
- 다른 사용자의 열려 있는 문서 저장·닫기
- 원본 자동 덮어쓰기
- 암호·DRM·배포용 문서·전자서명 우회
- 매크로 실행
- 외부 AI API나 문서 변환 서버 업로드
- Windows가 아닌 운영체제에서 네이티브 편집
