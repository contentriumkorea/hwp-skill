# 지원 환경과 제한 사항

## 요구 환경

- Windows
- Windows PowerShell 5.1 또는 PowerShell 7 이상
- 자동화 COM 인터페이스가 등록된 한컴오피스 한글
- 이미지 삽입·교체 및 PDF·쪽 이미지 내보내기에는 사용자가 공식 절차로 등록한 파일
  경로 보안 모듈

개발·통합 시험 환경은 한컴오피스 2024 Edu, 자동화 엔진
`13.0.0.711`, PowerShell `7.6.4`다. 한컴오피스 2018·2020·2022는 호환될 수 있으나
현재 저장소에서 실기 검증하지 않았으므로 검증 완료로 표시하지 않는다.

## 형식별 지원

| 형식 | 읽기·검사 | 편집 | 새 결과 | 비고 |
|---|---:|---:|---:|---|
| HWP | 지원 | 지원 | HWP | 원본 바이트를 메모리로 처리 |
| HWT | 지원 | 지원 | HWP | HWT 자체를 덮어쓰지 않음 |
| HWPX | 지원 | 미지원 | 미지원 | 안전한 ZIP/XML 패키지 검사만 제공 |

HWPX 검사는 ZIP 경로 탈출, 비정상 압축 크기, 외부 XML 개체를 차단한다. 한컴 자동화
엔진의 HWPX 메모리 입출력 지원이 확인되지 않아 현재 버전에서는 편집하지 않는다.
HWP/HWT 메모리 입력은 파일당 128MiB를 기본 안전 한도로 사용하며, 한도를 넘으면 전체
바이트를 읽기 전에 차단한다.

## 보안 모듈에 따른 조건부 기능

다음 기능은 한컴이 로컬 파일 경로를 열어야 하므로 보안 모듈 없이는 `BLOCKED`다.

- 이미지 삽입과 교체
- PDF 내보내기
- 한컴 네이티브 쪽 이미지 생성

일반 HWP/HWT 본문 읽기, 텍스트·필드·표·서식 편집, HWP 메모리 저장은 보안 모듈이
없어도 동작할 수 있다. 다만 문서 안의 특정 외부 연결 개체는 별도 제한이 생길 수 있다.

## 현재 구조 편집 한계

- 구역 설정은 A4, 가로·세로 방향, 상하좌우 여백만 지원한다.
- 다단, 제본 여백, 배경, 테두리, 각 구역의 복잡한 시작 쪽 설정은 지원하지 않는다.
- 기존 머리말·꼬리말과 기존 쪽 번호는 자동으로 덮어쓰지 않는다.
- 글자 서식은 크기, 굵게, 기울임을 지원하고 문단 서식은 정렬만 지원한다.
- 표 셀 병합·나누기, 행·열 삭제, 복잡한 셀 테두리·배경은 지원하지 않는다.
- 그림 교체 후 회전, 자르기, 텍스트 배치 등 모든 속성이 동일하다고 보장하지 않는다.
- 차례는 자동 갱신 필드가 아니라 현재 인쇄 쪽 번호로 만든 안전한 텍스트 차례다.
- 임의 OLE 개체, 복잡한 수식, 차트 내부 데이터, 매크로는 편집하지 않는다.

## 시각 검증 한계

문서의 본문과 구조 재검사는 네이티브 엔진으로 수행한다. PDF와 페이지 이미지 생성은
보안 모듈과 로컬 렌더러가 있을 때만 가능하다. 이 조건이 없으면 결과 상태는
`PASS_WITH_WARNINGS`이며 다음을 주장하지 않는다.

- 원본과 픽셀 단위로 동일함
- 줄바꿈과 페이지 나눔이 완전히 유지됨
- 글꼴 대체나 개체 잘림이 없음
- 모든 인쇄 설정이 동일함

중요한 공공문서 결과는 한글 프로그램에서 최종 페이지를 사람이 확인해야 한다.

## 제외 범위

- 사용자가 한글 프로그램에서 이미 열어 둔 문서의 직접 제어
- 다른 사용자의 열려 있는 문서 저장·닫기
- 원본 자동 덮어쓰기
- 암호·DRM·배포용 문서·전자서명 우회
- 매크로 실행
- 외부 AI API나 문서 변환 서버 업로드
- Windows가 아닌 운영체제에서 네이티브 편집

## 라이선스 구분

이 저장소의 코드는 MIT 라이선스다. 한컴오피스, HWP 자동화 API, 파일 경로 보안
모듈의 사용 권리는 별개다. 한컴 공식 안내에는 개인의 비상업적 자동화 이용과 상업적
이용 조건이 구분되어 있으므로, 회사·기관·납품 환경에서는 구현 코드를 사용하기 전에
최신 약관과 필요한 별도 승인 또는 계약을 한컴에 확인해야 한다.
