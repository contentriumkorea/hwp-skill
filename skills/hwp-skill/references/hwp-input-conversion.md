# 내장 HWP/HWT → HWPX 입력 변환

입력 확장자가 `.hwp` 또는 `.hwt`이면 AI가 먼저 별도의 HWPX 작업본을 만든다.
HWP 5.x 바이너리 입력만 대상이며 확장자를 바꾸는 작업이 아니다. 기존 `inspect`는
원본의 독립 대조와 진단을 위해 읽기 전용 동작을 유지한다.

## 실행

프로젝트 안의 작업 폴더를 만들고, 아직 존재하지 않는 출력 파일을 지정한다.
아래 `SKILL_ROOT`는 현재 설치된 이 스킬의 실제 절대 경로로 치환한다.

```powershell
& 'SKILL_ROOT/scripts/Invoke-HwpSkill.ps1' convert-hwpx -LiteralPath '입력.hwp' -OutputPath '작업폴더/입력.hwpx'
& 'SKILL_ROOT/scripts/Invoke-HwpSkill.ps1' inspect -LiteralPath '작업폴더/입력.hwpx'
```

AI가 명령·출력 경로·원본 대조를 관리한다. 성공한 결과의 `data.OutputPath`만 이후
HWPX 작업의 입력으로 사용한다. 재판독에서 받은 `address`와 원문을 사용해
`edit-hwpx`로 수정하며 HWP 원본의 순번·해시를 HWPX 주소로 재사용하지 않는다.
`generate -TemplatePath`의 구형 네이티브 양식 작성 경로로 돌아가지 않는다.

## 실행 환경

- PowerShell 외에 **64비트 표준 CPython 3.9 이상**이 필요하다. free-threaded 빌드는 제외한다.
- HwpForge 0.16.11 wheel 5종을 동봉한다: Windows x64, Linux x64/arm64(glibc 2.28+),
  macOS x64(10.12+)/arm64(11+). 네트워크 다운로드·pip 설치는 실행하지 않는다.
- 동봉 wheel의 SHA-256·버전을 검사하고, 사용자 site-package·환경 import 경로를
  비활성화한 별도 Python 프로세스에서 실행한다. 한컴·COM·보안 모듈은 사용하지 않는다.
- 런타임이 없거나 플랫폼이 맞지 않으면 이유를 알린다. 전역 설정 변경·자동 설치·GUI
  대체는 하지 않는다. 실제 운영체제별 실행 검증과 wheel 동봉 여부는 구분한다.

## 보존 검사와 차단

- 입력 크기 100MiB, 기존 휴대형 판독기의 보호·압축·레코드 안전 한도를 적용한다.
- 원본 읽기 핸들·SHA-256과 별도 스냅샷을 유지한다. 출력 덮어쓰기·정션/심볼릭 링크
  출력 경로를 거부한다. 변환 프로세스는 60초 제한이며 자체 프로세스만 종료한다.
- 엔진의 모든 변환 경고를 차단 사유로 취급한다. 경고가 없어도 독립 판독기로 문단별
  정확한 텍스트와 순서, 구역·용지·여백, 표 셀 주소·병합·크기·본문, 기본 글꼴·언어별
  글자 속성·문단 줄 간격·기본 테두리·셀 여백을 대조한다.
- 표의 셀 세로 정렬·쓰기 방향·기본 줄바꿈·셀 내부 쪽 나눔·제목 행 반복도 대조한다.
  복잡한 셀 줄바꿈·유효 영역 스타일, 다단·특수 제본·고급 구역 플래그와 머리말/꼬리말·
  필드 등 미검증 컨트롤은 아직 입력 변환에서 차단한다. 원본 읽기 지원 범위보다 좁다.
- 복잡한 글자 효과·미확정 테두리/채우기는 차단한다. 원본에 그림·수식·BinData가 있으면
  현재는 개체별 자산 대응을 독립 검증하지 못하므로 변환 결과를 승격하지 않는다.
  이미지가 빠진 문서로 대체하지 않는다. HWPX의 새 이미지 작성·수정 지원과는 별개다.
- 누름틀 등의 표시 문구가 바뀌면 중단한다. 실제 누름틀 보존을 일반 문자 치환으로
  대신하지 않는다. 미지원 요소를 빼거나 페이지를 그림으로 평탄화하지 않는다.
- 저장된 줄 배치 캐시는 HWPX 편집용 좌표가 아니므로 전달하지 않는다. 실제 한컴의
  줄바꿈·자동 쪽갈이·글꼴 대체·인쇄까지 같다고 보장하지 않는다.
- 실패하면 완성 출력 파일을 만들지 않고 원본을 보존한다. 중간 파일은 고유 작업 폴더
  안에서만 관리하고 정리한다. 안전한 정리가 불가능하면 남은 경로를 보고한다.
- 저장 직전에는 검증된 바이트를 다시 해시 대조하고 새 파일 생성 전용으로 기록한다.
  독립 대조는 지원한 속성의 검사이며 모든 한컴 기능·서식의 무손실 인증이 아니다.

## 엔진 출처

HwpForge는 AiScream Team의 MIT/Apache-2.0 이중 라이선스 프로젝트이며 이 스킬은
MIT 조건으로 정식 wheel을 재배포한다. 원본 wheel과 해시는
`vendor/hwpforge/manifest.json`, 고지는 `THIRD_PARTY_NOTICES.md`와
`licenses/HwpForge-MIT.txt`에 있다. Contentrium의 래퍼·독립 대조·승격 검사는 이 스킬의
코드다. 한컴오피스 설치 DLL 또는 비공개 코드가 포함된 변환기가 아니다.
