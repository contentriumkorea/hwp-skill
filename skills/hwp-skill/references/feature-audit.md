# 한글2024 기능 대조 대장

## 완료 상태

**전체 기능의 의미·실행 전수 검증은 미완료이며, 모든 기능을 지원하지 않는다.**
2026-10-19 설치본의 정적 목록·네이티브 코드와 공식 모델·스킬 코드·시험을 대조한 확장이다.
`capabilities`의 `authoring.coverageAudit`도 이 상태를 반환한다.

| 조사 범위 | 결과 | 근거와 한계 |
|---|---|---|
| `Hwp.UxXml.dll` 내장 XML | 14개, 고유 명령/참조 ID 1,798개 | 명령·속성·프레임·문맥 메뉴·단축키의 모든 Command/name 및 command 참조. 중복 출처와 정의 없는 참조도 유지 |
| `HwpObject.tlb` | 타입 255개, 함수 엔트리 7,668개 | REGKIND_NONE 읽기 전용. 상속/GET/PUT/중복 포함; 기능 개수 아님 |
| `HwpAutomation.tlb` | 타입 245개, 함수 엔트리 7,488개 | 같은 경계. COM 서버 실행·등록 없음 |
| 느슨한 Hwp 대화상자 XML | 파일 5개 식별/해시 | 전체 네이티브 대화상자를 뜻하지 않음 |
| REA 정적 증거 | Hwp/UX/엔진 메타데이터와 대화상자 DLL PE 리소스 | 대상 실행 없음. 원본 증거는 개발용 출력에 보존 |
| 추가 REA 코드 추적 | XMLDocGroup.DFT의 SECTION 처리, HncHDKDll의 MIME 확인·네임스페이스/로딩 분기 | 단순 문자열 검색에서 끝내지 않고 참조 함수 역컴파일. 가상 호출·독립 저장 ABI 미해결 |
| 공식 HWPX 모델 | 288개 CPP, 클래스 316개, 직접 저장 속성 723개, 하위 요소 등록 663개, 열거값 목록 103개 | 고정 커밋 전체 Class CPP의 리터럴 추출. 상속·조건·조판 의미 미해결. 기능 개수 아님 |
| 실행/조판 의미 | 부분 확인 | 직접 XML 기능은 시험. 한글 전체 메뉴 실행·인쇄 비교 미실시 |

컴파일된 BAML, CHM 도움말 내부, 런타임 생성 명령, 네이티브 코드의 모든 기능 분기는
이 목록으로 완전히 포괄하지 않는다. 따라서 1,798개를 한글의 전체 기능 수라고 부르지
않는다. 각 명령의 미검토 상태도 개발용 JSON에 `inventory-only`로 유지한다.

개발용 `tools/Export-HancomFeatureInventory.ps1`은 설치본을 실행하지 않고 재수집한다.
수집기와 한컴 바이너리/원문 XML은 설치용 스킬에 포함하지 않는다.

## 문서 기능별 대조

`직접`은 HWPX ZIP/XML 처리다. `보존/발견`은 개체의 완전한 의미 판독·수정을 뜻하지
않는다. 판정은 명령 이름의 존재가 아니라 현재 코드·시험을 기준으로 했다.

| HWP/HWT 열기 | 비보호 HWP 5.x 휴대형 판독 | HWP 3.x/97, 암호/배포용/DRM 판독 미지원 |

새 지원의 근거는 `HwpxCoverageUpgrade.Tests.ps1`이다. 기존 근거는

시험은 구조·값·자산·보존·실패 경계를 검사하며 한글 실제 조판을 증명하지 않는다.

`HwpxNoteSettings.Tests.ps1`, `HwpxReferenceEditing.Tests.ps1`이며 입력 계약은
[참조·탭 편집](reference-editing.md)을 따른다.

2.7.0의 추가 근거는 `HwpxParagraphMove.Tests.ps1`, `HwpxNamedStyle.Tests.ps1`,
`HwpxCellDiagonal.Tests.ps1`이며 입력 계약은 [추가 부분 편집](remaining-editing.md)을 따른다.

## 남은 구현·검증 순서

1. 참조 포함/컨테이너 간 본문 이동, 기존 목록·명명 스타일 전역 갱신, 구역 추가/삭제·재배열, 복잡한 머리말/각주 구조.
2. 임의 셀 분할/복잡한 대각선/캡션/표 변환, 다중키·명시 날짜 정렬, 참조 보존 계산 계획.
3. 기존 그림/기본 도형 수정, 실제 레이아웃을 측정하는 별도 무창 조판 엔진 검증.
4. 수식·차트·메모·변경 추적·참조·폼의 의미 모델과 호환 시험.
5. 컴파일 리소스/도움말/네이티브 코드와 명령 목록의 추가 대조 및 모든 명령의 의미 검토.

이 목록이 남아 있는 동안 전수 점검 완료 또는 한글 전체 기능 지원으로 보고하지 않는다.
