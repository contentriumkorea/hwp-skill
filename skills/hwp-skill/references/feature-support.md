# 기능별 실제 지원 범위

`지원`은 무창 로컬 구조 처리를 뜻한다. 실제 한글 렌더링과 인쇄 결과는 별도다.
기본 실행 환경은 Windows PowerShell 5.1 또는 Windows/macOS/Linux의 PowerShell 7.2 이상이다.
운영체제별 구조 테스트는 GitHub Actions에서 검증한다. 네이티브 편집은 별도 Windows 조건을 따른다.

조건부 시각 검증에는 **준비된 별도 무창 렌더러**가 필요하다. 없으면 화면을 열어 대체하지
않는다. HWPX 직접 작성·이미지 삽입에 보안 모듈은 필요 없다. 한컴 자체의 모든 기능이나
모든 기존 문서의 완전한 시각적 왕복 호환을 지원한다고 주장하지 않는다.

`preview`는 별도로 근사 HTML/PDF를 제공한다. PDF에는 Chromium headless가 필요하며,
근사 결과를 한컴 실제 페이지 수·줄바꿈 검증으로 간주하지 않는다. 기본 HWP 최종 변환은
격리 변환기 미제공으로 차단되며 HWPX 작업본이 보존된다.

세부 입력과 정확한 경계는 [작성 규격](authoring.md) 및 JSON 스키마를 따른다.

## 한컴오피스 2024 자동화 API와 이 스킬의 지원 구분

설치본의 형식 라이브러리에는 다수의 문서 편집·출력·보안 API 이름이 있지만, 이는 한컴
응용프로그램 자동화 표면을 정적으로 관찰한 것이다. 무창 문서 엔진이나 해당 기능의
실행 검증을 의미하지 않는다. `HwpConverter.exe`는 대화상자 초기화 과정에서 한글 COM
개체를 만들려는 경로가 확인되어 이 스킬의 silent 변환기에 사용하지 않는다.
`HwpApi.exe`도 문서 변환 CLI로 검증되지 않았다. 전체 근거와 버전은
[한컴오피스 2024 정적 분석 기록](hancom-2024-runtime-audit.md)을 참고한다.

따라서 이 문서 표에 명시된 HWPX 직접 처리와 HWP 5.x 휴대형 읽기만 현재 지원으로
간주한다. 한컴 UI 기능이 존재한다는 사실만으로 표의 미지원 항목을 지원으로 바꾸거나,
한컴 창·COM·보안 모듈을 자동 실행하지 않는다.
