# HWP Skill 신뢰성·이식성 업그레이드 구현 계획

**목표:** 재현된 문단 대상 오류, 최종 HWP 검사 누락, 현재 세션의 숨김 한컴 실행을 수정하고 기존 문서 편집·무창 미리보기·운영체제 독립 읽기·자동 배포 검사를 확장한다.

**구조:** 읽기 결과에 수정 가능한 안정된 주소를 제공한다. HWPX 작성·편집은 기존 ZIP/XML 경로를 유지한다. HWP 최종 변환은 현재 데스크톱 COM을 사용하지 않으며, 검증 가능한 무창 변환기가 없는 기본 환경에서는 작성된 HWPX를 보존하고 HWP 납품을 차단한다. 최종 변환 결과는 바이너리 시그니처뿐 아니라 실제 논리 내용을 다시 읽어 검사한다.

**기술:** PowerShell 5.1/7, .NET 관리 코드 CFB 판독기, HWPX XML, Chromium 계열의 headless PDF 인쇄, Pester 3.4.

## 공통 조건

- 원본 해시·미지원 XML 보존, 사용자 한컴·Word 창 실행 및 제어 금지.
- 새 문서 A4 세로·160%·문단 앞뒤 0, 추가 공간은 빈 문단의 글자 크기로 조절.
- 실제 한컴 조판과 근사 HTML/PDF 미리보기를 명시적으로 구분.
- 기존 파일은 덮어쓰지 않으며 문서·이미지는 외부로 전송하지 않는다.
- 수정 전 재현 → 수정 → 회귀 검사. 로컬 설치본과 GitHub 게시본을 대조한다.

## 작업과 검증

- [x] 읽기·수정 주소: `HwpInspect.psm1`, `HwpHwpxScopedEdit.psm1`에 안정된 주소를 연결하고 표 뒤 문단·여러 구역·셀 문단의 대상 일치를 실제 결과로 검사한다.
- [x] 기존 문서 편집: 셀 내용, 이미지 교체, 머리말·꼬리말 및 지원 가능한 단순 표 확장. 복잡한 병합·알 수 없는 대상은 부분 성공으로 숨기지 않는다.
- [x] HWP 변환: 현재 세션 COM 실행 제거, 실제 본문·표 재검사. 그림별 참조를 아직 검증하지 못하므로 이미지 포함 HWP는 승격하지 않는다. 잘못된 실제 HWP fixture와 이미지 참조 모의 검사로 거짓 성공을 차단한다.
- [x] 운영체제 독립 읽기: `HwpCompoundFile.cs`를 FAT/DIFAT/miniFAT/디렉터리를 직접 해석하는 관리 코드로 전환한다. 정상 HWP/HWT, 체인 순환·범위 밖 섹터·절단 스트림을 검사한다.
- [x] 무창 미리보기: `HwpPreview.psm1`의 `Export-HwpxPreview -LiteralPath -OutputDirectory`로 HTML과 Windows headless PDF를 생성한다. HTML 이스케이프·내장 이미지·병합 표·구역 방향·원본 해시를 검사한다. 한컴 조판 미검증 표시를 필수로 유지한다.
- [x] 공개 CLI·기능표·한국어 안내를 구현과 일치시키고 버전 메타데이터를 제공한다.
- [ ] GitHub Actions에서 Windows 검사 및 Linux/macOS 휴대형 검사·패키징을 실행한다. 태그 기반 배포에 ZIP·해시를 포함한다.
- [ ] 전체 회귀 검사, 설치본 갱신, GitHub 게시와 원격 커밋/파일 검증을 완료한다.

## 알려진 구현 경계

별도 Windows 세션·가상 머신 또는 정식 headless HWP 변환 제품을 이번 작업에서 설치하거나 라이선스 없이 포함하지 않는다. 기본 배포는 HWPX 작성·편집·근사 미리보기와 HWP 읽기를 완성하고, 준비되지 않은 HWP 최종 변환을 성공으로 보고하지 않는다. 운영체제별 실행 여부는 실제 CI 결과로 보고한다.
