# HWP 다중 엔진 구현 로드맵

기준 설계:
`docs/superpowers/specs/2026-08-16-hwp-multi-engine-design.md`

## 목적

승인된 설계를 독립적으로 검토하고 시험할 수 있는 다섯 구현 묶음으로 나눈다. 각
묶음은 이전 묶음이 제공하는 공개 인터페이스만 사용하며, 구현 전에 별도의 상세
계획을 승인된 설계와 대조한다.

| 4 | 렌더링과 격리형 한컴 검증 | 전 페이지 검사와 네이티브 시각 등급 | 1, 2, 3 |

## 단계별 품질 게이트

각 구현 묶음은 다음 조건을 통과해야 다음 묶음의 기준이 된다.

1. 새 동작을 증명하는 실패 시험을 먼저 실행한다.
2. 최소 구현으로 새 시험과 기존 정적 시험을 통과한다.
3. 원본 보존과 외부 전송 금지 정책을 유지한다.
4. `silent` 경로에서는 현재 사용자 세션에 GUI 프로세스를 만들지 않는다.
5. 지원하지 않는 기능은 자동 GUI 대체 없이 명시적으로 차단한다.
6. 공개 인터페이스와 실제 시험 결과를 문서에 동일하게 반영한다.
7. 단계별 커밋을 독립적으로 검토할 수 있게 유지한다.
