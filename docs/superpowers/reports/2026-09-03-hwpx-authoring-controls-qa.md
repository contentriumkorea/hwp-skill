# HWPX 작성 제어 확장 검증 결과

검증일: 2026-09-03. 승인된 A~C 구현과 로컬 설치 갱신을 마쳤다.
GitHub 공개와 main 통합은 아직 수행하지 않았으며 사용자 선택에 따른다.

## 반영 범위

- A: 세로/가로의 저장 치수와 화면 치수 구분, 용지·여백·구역·제본·다단·쪽 테두리,
  부모 영역에 맞는 표/그림 폭, 엄격한 V1/V2 입력 검증과 잘못된 속성 사전 거부.
- B: 부분 글자 서식·문단·목록·탭·명명 스타일, 병합 표·열 폭·셀 서식·제목행 반복,
  그림 포함·비율·위치·자르기·회전·캡션과 기본 도형.
- C: 머리말·꼬리말·번호·필드·책갈피·링크·각주·미주·링크 차례,
  원본 보존형 HWPX 부분 수정, 기능표·한국어 사용 규격·범용 패키지.

작성과 수정은 HWPX ZIP/XML 직접 처리다. 이미지 바이트는 BinData에 포함하고 원본
SHA-256과 대조한다. 한컴 GUI, 보안 모듈 등록, 사용자 문서 업로드를 사용하지 않았다.

## 자동 검증

| 검증 | 결과 |
|---|---|
| PowerShell 7 전체 Static | 422 통과, 실패 0 |
| Windows PowerShell 5.1 전체 Static | 419 통과, 실패 0, 3개 제외 |
| 무창·포커스 보존 시험 | 두 버전의 전체 Static 안에서 각 8개 통과 |
| 원본 보존형 부분 수정 | 65개 회귀 시험 포함 |
| 독립 생성 계약 검증 | 67개 회귀 시험 포함 |
| 새 프로세스의 생성/편집 ZIP 표식 | 두 버전에서 실제 method 0 확인 |
| Codex 설치본·PowerShell 7 | 41개 파일 해시 일치, 실제 생성/재읽기, 독립 검사 31개 통과 |
| Claude 설치본·PowerShell 5.1 | 41개 파일 해시 일치, 실제 생성/재읽기, 독립 검사 31개 통과 |
| 스킬 메타데이터 검사 | 통과 |

5.1에서 제외한 3개는 Test-Json을 사용하는 편집/표 검사 스키마 전용 시험이며, 같은
검사는 7에서 통과했다. 새 작성/기능 스키마의 표준 검사에는 시험용 PowerShell 7을
사용한다. 설치된 5.1 작성 엔진 자체에는 PowerShell 7을 필수 의존성으로 추가하지 않았다.

기존 설치본은 각 도구의 skills/.hwp-skill-backups 아래에 보관했다. 업데이트 중 발견한
5.1 ZIP 압축 방식 차이를 수정한 후 설치본을 다시 갱신하고 두 설치 경로를 재검사했다.

## 독립 문서 인수

합성 자료로 A4 세로 → A4 가로 → A5 세로, 18pt 굵은 제목/11pt 본문, 3열 병합 표,
실제 PNG, 링크 차례와 각주를 만들었다. 생성기와 별개인 ZIP/XML 검사로 내용 순서,
용지 속성, 스타일 참조, 병합 그리드, 필드 연결 및 이미지 바이트를 대조했다.
쪽 번호 차례와 변경 추적 요청은 정확한 속성 경로를 반환하며 결과 파일 생성 전에 차단했다.

재현 가능한 회귀 시험은 tests/에 있다. 현장 실행 로그와 합성 산출물은 Git에서 제외한
tests/output/authoring-final-static.xml, authoring-all-ps51.xml 및
behavior-acceptance-20260903-181018-installed-Codex/,
behavior-acceptance-20260903-181024-installed-Claude/에 보관했다.

## 남은 한계

- 실제 한글 조판, 글꼴 대체, 자동 쪽 수와 인쇄 결과는 렌더링 검증하지 않았다.
  구조 검사 통과를 픽셀 수준 일치나 한컴의 모든 기능 지원으로 표현하지 않는다.
- 수식·차트·변경 추적·복잡한 그룹·OLE 작성과 인쇄 쪽 번호 차례는 미지원이다.
- 부분 수정은 명시한 지원 작업에 한정한다. 복잡한 표와 알 수 없는 대상 개체를 추정해서
  수정하지 않는다. 변경하지 않은 ZIP 파트의 내용과 확장 XML은 보존한다.
- 별도 행동 시험의 WMI 프로세스 시작 이벤트 구독은 권한 문제로 사용할 수 없었다.
  해당 로그는 전후 프로세스 비교만 제공하며, 순간 이벤트 감지 성공으로 주장하지 않는다.
  별도의 전체 Static 무창/최상위 창/포커스 감시 시험은 통과했다.
- 실제 Hancom Native 통합 시험은 실행하지 않았다. Native/All 명령은 승인 없이 차단되며,
  가상 COM 시험 통과를 실제 한글 렌더링 확인과 혼동하지 않는다.

일반 사용 안내와 정확한 지원 경계는 skills/hwp-skill/references/authoring.md 및
feature-support.md를 따른다.
